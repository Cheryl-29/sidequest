# M0 probe observations

Each timestamped directory contains request metadata, raw public API responses and SHA-256 hashes. These are observations, not verified itineraries or production fixtures. Failed responses are retained; no API credentials are stored.

OSM responses: © OpenStreetMap contributors, [ODbL](https://www.openstreetmap.org/copyright). Preserve attribution and comply with ODbL when distributing this database or derivatives.

Weather responses: [Open-Meteo](https://open-meteo.com/), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Free API access conditions are separate from the data license.

Transport responses: Transport for NSW Trip Planner API, licensed as Creative Commons Attribution by its dataset page. Attribute Transport for NSW, do not imply endorsement, and treat route observations as time-sensitive. API credentials are never stored in these directories.

See ../../docs/data-feasibility.md for denominators, limitations and the incomplete M0 gates.
